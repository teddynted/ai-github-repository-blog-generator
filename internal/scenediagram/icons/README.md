# Official AWS Architecture Icons

These SVGs are the **official AWS Architecture Icons** (64px), from the
AWS Architecture Icons asset package: https://aws.amazon.com/architecture/icons/

They are used only to compose architecture diagrams (the intended use), per the
AWS Architecture Icons terms. Update by re-downloading the current asset package
and re-copying the `Arch_*/64/Arch_*_64.svg` files with the filenames below.
