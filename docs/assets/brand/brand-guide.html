06 · Rationale

Why it works

Symbolism

The commit trunk and two nodes are the universal Git-branch glyph — instant shorthand for a repository and for version history. Read a second way, the connected nodes are a neural network: engineering and AI share the same geometry. The branch peeling off the trunk is the automated pipeline; where it lands, it resolves into a four-point spark — the modern signifier for generated intelligence, and here the blog post, release summary, or script the platform produces.

Why this palette

GitHub black (#24292F) ties the structure to the developer world the tool lives in; AI blue (#2563EB) is reserved exclusively for the spark, so the eye reads “code → intelligence” in one glance. Cyan and purple are used only as a small secondary spark, signalling that one input generates many outputs — without resorting to a gradient. The neutrals borrow GitHub’s Primer bias so the brand feels native inside a repo, a README, or a CLI.

How it says “AI-generated content”

Motion is implied in the silhouette: the eye travels up the trunk, along the branch, into the spark — input becoming output, a repository becoming published writing. The spark is deliberately the brightest, highest-contrast element, so “generation” is the last thing you read and the thing you remember.

How it scales

The whole mark is built from four primitives — two dots, two strokes, two spark polygons — on a tidy 48-unit grid with rounded caps. There is no fine detail to collapse, so it stays crisp from a 512 px avatar to a 16 px favicon, and it flattens perfectly to a single color for stamps, embroidery, or a terminal glyph.

Open-source fit

Every asset is pure, hand-readable SVG on a transparent ground, themed with currentColor so a README picks up the reader’s light or dark mode automatically. It sits comfortably in the company of Docker, Terraform, and the GitHub CLI: one idea, executed simply, and impossible to mistake for anything else.
